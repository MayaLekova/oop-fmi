# Материали от семинари по "Обектно-ориентирано програмиране"
*летен семестър 2025/2026, Компютърни науки, група 3*

## Съдържание
- [**Тема 1**](./week-01) - Преговор от УП (структури, динамична памет, указатели към функции).
- [**Тема 2**](./week-02) - Енумерации и структури.
- [**Тема 3**](./week-03) - Член-функции. Указателят this. Static.
- [**Тема 4**](./week-04) - Предефиниране на оператори. Жизнен цикъл на обектите - конструктори, деструктор. Капсулация. Класове. Голяма тройка/четворка (rule of three/four).
- [**Тема 5**](./week-05) - Ламбда функции. std::function. Map, reduce, filter. Реализация на динамичен масив.
- [**Тема 6**](./week-06) - Шаблон на колекция - клас за множество с максимален брой елементи (BoundSet). Преговор - оператори за събиране на множества (operator+, operator+=).
- [**Тема 7**](./week-07) - Шаблонна имплементация на свързан списък. Разделна компилация - разделяне на дефиниции и имплементации в .h/.hpp и .cpp файлове.
- [**Тема 8**](./week-08) - Въведение в полиморфизъм, пример с йерархия от животни. Виртуално извикване на методи.
- [**Тема 9**](./week-09) - Работа с текстови файлове - пример за таблица с оценки. Записване на двоични файлове - пример с мениджър на ресурси в игра.
- [**Тема 10**](./week-10) - Итератори. Преговор - наследяване и полиморфизъм. Шаблон за дизайн `singleton`, пример с регистър на команди. 
- [**Тема 11**](./week-11) (текуща) - Преговор - поморфизъм, реализация на рекурсивен парсър (недовършена).
