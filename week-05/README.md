# Указатели към функции. std::function. Ламбда изрази. Map, reduce, filter.

## Указател към функция
Функциите в C++ имат адрес в паметта, точно като обектите. Можем да пазим този адрес в **указател към функция**. Указателите към функции имат следния вид:
```c++
<тип на връщане>(*<име>)(<тип на параметър 1> [<име на параметър 1>], <тип на параметър 2> [<име на параметър 2>], ..., <тип на параметър n> [<име на параметър n>])
```
Наблюдение е, че не е задължително декларирайки указател към функция да се дават имена на параметрите - само типовете са достатъчни.

```c++
int add(int a, int b) {
    return a + b;
}

int main() {
    int (*fp)(int, int) = add; // указател към функция, приемаща два int и връщаща int
    int (*fp2)(int first, int second) = add; // същото като горното
    std::cout << fp(3, 4); // 7
}
```

### Using и typedef
Тук може да се възползваме от *using*, с който можем да дадем псевдоним на даден тип. Подобно е на *typedef*, но с по-четим синтаксис. Работи и за не-указателни типове:
```c++
using BinaryOp = int(*)(int, int);

BinaryOp fp = add;
fp(3, 4); // 7

using ComplexNumber = double[2];
using HadamardGate = ComplexNumber[2][2];
using Matrix = int[4][4]; // псевдоним за масив
using Predicate = bool(*)(int); // указател към функция bool(int)
using Transform = int(*)(int); // указател към функция int(int)
```

Особено полезно е когато типът се ползва на много места, тъй като смяната на сигнатурата изисква промяна само на едно място:
```c++
using Comparator = bool(*)(int, int);

void sort(int* arr, int n, Comparator cmp);
int  findIf(int* arr, int n, Comparator cmp);
// ако сигнатурата се промени, редактираме само using-а
```

Указателите към функции са удобни, когато искаме да имаме функция, която да може да извършва множество различни действия, които изглеждат еднотипни. Например, ако напишем функция, която приема масив и променя всички негови елементи по някакъв начин, можем да приемем указател към функция, която да извикваме за всеки елемент на масива. По такъв начин, ако например искаме да можем да умножим всяко число на масива по 2, да добавим 1 към всеки елемент на масива и да разделим всеки елемент на 5, няма да се налага да пишем 3 различни функции, които реално ще изглеждат напълно еднакво (с изключение на един ред):
```c++
using Transform = int(*)(int);

void map(int* arr, int n, Transform transform) {
    for (int i = 0; i < n; i++) {
        arr[i] = transform(arr[i]);
    }
}

int doubleIt(int x) { return x * 2; }
int addOne(int x) { return x + 1; }
int divideByFive(int x) { return x / 5; }

int main() {
    int arr[] = {1, 2, 3, 4};
    map(arr, 4, doubleIt); // {2, 4, 6, 8}
    map(arr, 4, addOne); // {3, 5, 7, 9}
    map(arr, 4, divideByFive); // {0, 1, 1, 1}
}
```
Още повече, пишейки само 1 функция, обхождаща масива и променяща стойностите му, вместо 3 такива, при намиране на потенциален проблем ще се наложи да променим кода само на 1 място, вместо на 3 места.

## Ламбда изрази
### Проблемът с указателите към функции — не можем да обхващаме локални или други променливи
Указателят към функция е просто адрес. Той не носи никакъв контекст, тоест няма как да запомняме локални променливи.

```c++
using Transform = int(*)(int);
void map(int* arr, int n, Transform transform);

int main() {
    int factor = 5;

    map(arr, n, [](int x) { return x * factor; }); // compile-time error - local variable in anonymous functions
}
```

За да заобиколим това с обикновена функция, трябва да ползваме глобална или статична променлива, което не е добра практика.  

```c++
using Transform = int(*)(int);
void map(int* arr, int n, Transform transform);

int main() {
    int factor = 5;

    map(arr, n, [factor](int x) { return x * factor; }); // compile-time error
}
```

Това е начинът да обхванем променливи, които ни трябва. В този случай обаче пак няма да се компилира, понеже `[factor](int x) { return x * factor; }` вече става друг тип (std::function), който не може да се присвои към указател на функция.
Решението са  така наречените *ламбда изрази*.

### Ламбда изрази

Ламбда изразът е анонимна функция, която може да **capture-ва** (прихваща) променливи от обграждащата област на видимост (scope). С други думи, ламбда изразът е анонимна функция, на която можем да подаваме променливи, дефинирани извън нея, и тя да ги използва. 
Ламбда изразът съдържа няколко основни части:
- *capture клауза* - в нея се изброяват променливите, които се подават от външния свят, за да може да бъдат използвани от функцията
- *параметри на функцията*
- *тип на връщане* - в повечето случаи може да се избегне, понеже компилаторът се досеща какво връща функцията
- *тяло на функцията*

```
[capture](<тип на параметър 1> <име на параметър 1>, <тип на параметър 2> <име на параметър 2>, ..., <тип на параметър n> <име на параметър n>) -> [<тип на връщане>] { тяло }
```

```c++
std::function<int(int)> square = [](int x) { return x * x; };
std::cout << square(5); // 25
```

#### Capture клаузата
Тук е ключовата разлика спрямо обикновените функции. Както казахме, capture клаузата се използва за подаване на променливи от външния свят, които функцията ни да използва.
Това може да стане по 2 начина:

##### Capture по стойност
Копира стойността в момента на дефиниране на ламбдата. Същото като подаване на параметър по копие на функция:
```c++
double taxRate = 0.2;

std::function<double(double)> priceWithTax = [taxRate](double price) {
    return price * (1 + taxRate);
};

priceWithTax(100.0); // 120.0

taxRate = 0.5;
priceWithTax(100.0); // все още 120.0, защото копирахме taxRate в дефиницията на ламбдата
```

##### Capture по референция
Външната променлива се подава по референция, тоест всяка промяна върху нея в тялото на функцията ще се отрази и извън нея:
```c++
DynArray<MyString> log;

std::function<void(const MyString&)> addToLog = [&log](const MyString& msg) {
    log.add(msg); // класът DynArray е измислен за примера и представлява динамичен масив. Функцията add добавя елемент в края на масива.
};

addToLog("User logged in"); // log = ["User logged in"]
addToLog("File opened"); // log = ["User logged in", "File opened"]
```

##### Смесен capture
```c++
int minAge = 18;
int maxAge = 65;
MyString blockedName = "Admin";

std::function<bool(const Person&)> isEligible = [minAge, maxAge, &blockedName](const Person& p) {
    return p.age >= minAge && p.age <= maxAge && p.name != blockedName;
};
```

В крайна сметка можем да обобщим capture-ването на променливи така:
| Синтаксис | Значение |
|-----------|----------|
| `[x]`     | capture-ва `x` по копие |
| `[&x]`    | capture-ва `x` по референция |
| `[=]`     | capture-ва всичко по копие |
| `[&]`     | capture-ва всичко по референция |
| `[=, &x]` | всичко по стойност, но `x` по референция |
| `[this]`  | capture-ва текущия обект (в методи) |

## std::function
*std::function* (от *\<functional\>*) е wrapper, който може да съдържа **всичко, което може да се извика с оператор() (callable)** — функция, ламбда (дори с capture), функтор.

```c++
#include <functional>

std::function<int(int, int)> op;

op = [](int a, int b) { return a + b; };
op(3, 4); // 7

int factor = 5;
op = [factor](int a, int b) { return (a + b) * factor; }; // работи
op(3, 4); // 35
```

Сега `map` може да приема всичко, което е callable:
```c++
void map(int* arr, int n, std::function<int(int)> transform) {
    for (int i = 0; i < n; i++) {
        arr[i] = transform(arr[i]);
    }
}

int main() {
    int arr[] = {1, 2, 3, 4};
    int bonus = 10;
    map(arr, 4, [bonus](int x) { return x + bonus; }); // {11, 12, 13, 14}
}
```

**Относно `[&]` — ако ламбдата надживее scope-а на прихванатата променлива, оставаме с висяща референция към нещо, което вече е изтрито, така че ще имаме undefined behavior!**

```c++
#include <iostream>
#include <functional>

std::function<int()> makeLambda() {
    int x = 42;
    return [&x]() { return x; };
}

int main() {
    std::function<int()> identity = makeLambda();
    std::cout << identity(); // функцията използва променливата x, но към момента на извикването на identity тук,
                             // тази променлива вече е освободена (понеже е локална за функцията makeIdentity)
                            // и затова резултатът от това извикване не е ясен
}
```

### Ламбди и указатели към функции

Ламбда **без capture** може имплицитно да се конвертира до указател към функция:

```c++
int (*fp)(int) = [](int x) { return x * 2; };
```

```c++
int factor = 3;
int (*fp)(int) = [factor](int x) { return x * factor; }; // не се компилира - с capture клауза не може
```
